# Contributing to React Notification Kit

Thank you for your interest in contributing to `react-notification-kit`! We welcome all contributions to make this notification library even better.

## Development Workflow

1. **Fork and Clone**: Fork this repository on GitHub, then clone your fork locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/react-notification-kit.git
   cd react-notification-kit
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Check Types & Tests**:
   - Run type checking:
     ```bash
     npm run typecheck
     ```
   - Run tests:
     ```bash
     npm run test
     ```

4. **Make Changes**:
   - Write clean, documented code.
   - Maintain clean CSS styling using modern CSS custom properties.
   - Ensure all changes are covered by unit tests.

5. **Build Check**:
   - Run the build script before opening a pull request to ensure compiling succeeds:
     ```bash
     npm run build
     ```

6. **Submit PR**: Push your changes to your fork and submit a Pull Request targeting the `main` branch.

## Code of Conduct

Please treat everyone with respect and empathy. We are committed to fostering an inclusive, welcoming community.
