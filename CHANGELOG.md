# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-19

### Added
- Complete Toast System with success, error, warning, info, loading, custom, and promise-based states.
- Fully accessible Modal Dialog system supporting WCAG standard roles, labels, focus trapping, and ESC closing.
- Promise-based Confirmation Dialogs supporting loading animations during async onConfirm operations.
- Dynamic Theme configuration (light, dark, system).
- Vanilla CSS customization utilizing custom properties.
- Type declarations, CJS and ESM exports.
- Complete Vitest unit testing.
